# PMC Civic Signal

PMC Civic Signal is a FastAPI + Leaflet ward-news and social-intelligence portal for Pune Municipal Corporation.

It combines PMC ward boundaries with civic reports from public PMC Facebook/Instagram post links, RSS news and optional public social sources. Marathi, Hindi and English content can be classified and enriched through deterministic rules and optional Sarvam AI. Optional Gemini/Claude briefs provide draft ward-action summaries.

The frontend is intentionally kept in a single `static/index.html` containing HTML, CSS and JavaScript.

See `README_DEPLOYMENT.md` for installation and deployment.
